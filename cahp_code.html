案例分析

首都地区住房合作伙伴

Capital Area Housing Partnership 是一家位于密歇根州东兰辛市的非营利组织。我们的项目致力于调研客户对其网站的疑虑，并提交可交付成果以满足客户的需求。我们建议的改进旨在提高可访问性，并为网站用户创建实用的界面。

角色

UX 研究员

项目周期

2023年秋季

调研方法与审计

全面分析以识别现有平台中的入门障碍和可用性摩擦点。

code

W3C 标记验证

该网站通过了 W3C 标记验证服务的运行。结果出现多个 HTML 问题：解析错误、不完整的属性错误、杂散的结束链接、空格错误和无效的颜色语法。这些会导致渲染错误并阻碍辅助设备的使用。

accessibility_new

无障碍测试

75/100

未能为链接提供可识别的文本，未能达到 WCAG A 级标准。标题语义排序的问题为使用辅助技术的用户造成了障碍。屏幕阅读器测试通过以确保基本支持。

bug_report

WAVE 工具分析

专门通过 WAVE 工具运行了捐赠页面。发现了 HTML 错误、字体大小错误、颜色对比度错误和结构元素错误。影响可感知性、可操作性、可理解性和鲁棒性。

核心发现与建议

将审计发现转化为可操作的结构化解决方案，以改善核心用户体验。

问题 01

问题 01：标题层级与结构

网站未能通过视觉和结构可访问性测试，特别是标题（从 H1 到 H6）缺乏正确的层级顺序。

解决方案

解决方案：语义重构

在 HTML 中以 1 级标题作为主标题开始。然后仔细遵循正确的层次结构顺序（级别 2、3 等），以确保屏幕阅读器能够准确解释页面结构。

问题 02

问题 02：HTML 解析与属性

各种 HTML 问题给辅助技术和渲染错误带来了困难。具体来说，是解析错误和元素缺少必需的属性。

解决方案

解决方案：代码重构

强制执行正确的 CSS 语法用于选择器并完成动画属性。系统地审核并完成网站中所有 `` 元素缺失的属性。

问题 03

问题 03：捐赠流程体验与对比度

导航栏中有多个颜色对比度错误。捐款页面包含信息过载、主要操作按钮放置不当以及支付方式路由不连贯的问题。

解决方案

解决方案：捐赠页面重新设计

彻底重新设计捐赠页面，以提供更易于访问和直观的 UI，同时牢记我们的原型角色（Cathy Johnson）。简化支付路由并修复导航对比度。

界面重构设计

高保真模型侧重于清晰的导航、改善的对比度以及无摩擦的捐赠体验。

导航与对比度优化

修复了颜色对比度问题。实现了悬停状态颜色变化和一个备用下拉栏，以方便访问捐赠选项，减少不必要的滚动。

“了解更多”跳转逻辑

“了解更多”页面提供上下文信息，并允许用户通过清晰的分层操作调用，轻松路由到“在线捐赠”和“邮寄捐赠”选项卡。

嵌入式捐赠流程

  • check_circle 两个主要选项：一次性和每月订阅。
  • check_circle 预选支付层级以及自定义金额输入。
  • check_circle 集成支付方式（PayPal、银行、信用卡）。
  • check_circle 简化姓名、电子邮件、电话和可选消息的输入。
lightbulb

项目反思

在本次项目中，通过分析 HTML 结构错误、标题层次不正确和视觉对比度不足等问题，我们认识到以用户为中心设计网站的重要性。颜色必须提供足够的对比度，每个功能都应支持可用性，而简单的导航有助于用户快速了解他们需要采取的步骤。
